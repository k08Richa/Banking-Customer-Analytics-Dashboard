# Banking Customer Analytics Dashboard

## Overview
An end-to-end data analytics project built using Excel, SQL, and Power BI 
analysing banking customer transaction data.

## Objective
Analyse customer demographics, transaction patterns, spend behaviour, 
and loan risk profiles across 500 customers and 2,000 transactions.

## Tools Used
- Microsoft Excel (data exploration and validation)
- SQL / SQLite Online (querying and aggregation)
- Power BI Desktop (interactive dashboard)

## Key Findings
- Deposits drove 53% of total transaction value (₹59.42M)
- Chennai and Lucknow ranked as top locations by transaction volume
- Car loan customers maintained highest average account balance (₹4.73L)
- Savings accounts represented 60.6% of the customer portfolio
- Automatic transmission cars (in salary prediction sub-analysis) 
  showed highest average resale value

## SQL Queries Used
SELECT, GROUP BY, ORDER BY, ROUND, COUNT, AVG, SUM across 
7 analytical queries covering customer segmentation, spend patterns, 
loan risk profiles, and monthly transaction trends

## Files
- `Banking_Dataset.xlsx` — Customer and transaction data (2 sheets)
- `SQL_Queries.sql` — All 7 queries with comments
